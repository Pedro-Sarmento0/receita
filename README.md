# Receita

Projeto desenvolvido com o objetivo de praticar desenvolvimento web, criando uma aplicação simples para visualizar e organizar receitas.

## Funcionalidades

- Visualização das receitas cadastradas.
- Interface simples e fácil de usar.
- Organização das informações de cada receita.

## Tecnologias utilizadas

- HTML
- CSS
  
## Objetivo

Esse projeto foi criado para colocar em prática conceitos de desenvolvimento web, principalmente estruturação de páginas e estilização.
